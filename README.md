# מערכת ניהול שעות עובדים

מערכת פשוטה ונוחה לניהול שעות העבודה החודשיות של עובדי המסעדה.

## יכולות עיקריות

- הזנת שעות כניסה ויציאה וחישוב שעות אוטומטי.
- שמירה אוטומטית בדפדפן.
- מילוי מהיר של ימי עבודה ריקים.
- סיכום חודשי וייצוא ל־Excel.
- יום ראשון סגור, יום שישי עד 17:00 ושבת יום עבודה רגיל.
- בחירת שנים מ־2025 עד 2035.

## הפעלה

פתחו את הקובץ `index.html` בדפדפן. אין צורך בהתקנה.
