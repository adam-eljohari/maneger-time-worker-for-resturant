# זמן צוות

אפליקציית React לניהול שעות העובדים במסעדה, מותאמת במיוחד לטלפון.

## יכולות

- דיווח שעות לפי עובד ויום, עם חישוב אוטומטי.
- יום ראשון סגור, יום שישי עד 17:00 ושבת יום עבודה רגיל.
- מילוי חכם, סיכומים חודשיים וייצוא ל־Excel.
- ניהול עובדים ושמירה אוטומטית בדפדפן.
- התקנה בטלפון כאפליקציית PWA.

## הפעלה מקומית

```bash
npm install
npm run dev
```

לבניית גרסת ייצור:

```bash
npm run build
```

הקבצים המוכנים ייווצרו בתיקייה `dist`.
